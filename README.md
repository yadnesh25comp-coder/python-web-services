# Connecting Python Applications to Web Services

Mini project for learning how Python applications talk to web services (REST APIs) using the `requests` library.

**Name:** Yadnesh Mahendra Patil
**Roll No:** 343 | **Division:** C
**College:** Pillai College of Engineering (PCE), New Panvel

## What this project covers
- GET request and reading JSON responses
- POST request with a JSON payload
- Error handling (timeouts, HTTP errors, network errors)
- A small weather checker using OpenWeatherMap

## Files
- `web_service_demo.py`: GET, POST and error handling demo (JSONPlaceholder API)
- `weather_checker.py`: City weather checker (needs a free OpenWeatherMap API key)
- `requirements.txt`: Python dependencies
- `output.png`: Screenshot of the program output

## How to run
```bash
pip install -r requirements.txt
python web_service_demo.py
```
